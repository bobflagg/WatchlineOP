# Q17: Missing, lapsed or stale registration

**Fixture status:** Examples are provisional until verified against the selected frozen snapshot, pinned BOR release, or versioned retrieval cache, as applicable. Existing local checks retain their stated query dates; they are not a frozen acceptance baseline. See [expected-answer policy](../roadmap.md#expected-answer-policy).

## Question

> Is this building's registration missing, lapsed, or older than the latest deed transfer? Does the building meet the unit threshold of the registration dataset (3+ units), so that a gap is worth reporting?

### Sub-questions

CLaRO-style cleanup (stage 1, 2026-11-18). The parent asks for three conditions and a threshold on one lot. No new graph element: `Lot` (`hpdRegistered`, `unitsRes`, `yearBuilt`, `plutoNumBuildings`), `Registration` with `HAS_REGISTRATION` dates (Q2) and `Deed` (Q3) exist. The conditions are computed at answer time against one as-of date (the snapshot date of the registration data, 2026-05-29), not stored. Q17 passes when all four pass.

| ID | Sub-question | Answer requirements covered |
| --- | --- | --- |
| Q17.1 | Does the dataset hold no registration at all for this lot (missing), and how many registrations and buildings does it hold against PLUTO's building count? | 1 (missing), 3 (snapshot dates) |
| Q17.2 | Has every registration of this lot ended before the as-of date (lapsed), with each registration's dates? | 1 (lapsed, with dates), 3 |
| Q17.3 | Is the lot's latest registration date earlier than the date its latest deed was recorded (older than the latest deed), with both dates? | 1 (older than the latest deed, with dates), 3 |
| Q17.4 | How many residential units does PLUTO record for the lot, against the 3-unit threshold? | 2 (units, threshold) |

### Hidden assumptions made explicit (profiled 2026-11-18)

| Assumption | Rule |
| --- | --- |
| The building has a registration | HPD registers a building (BIN) under a lot. The graph and the dataset answer at the lot: a lot with no registration row is `missing`. A lot with some registered buildings can still hold an unregistered one, so the answer gives the registered buildings beside PLUTO's count (the two differ for about 27 percent of lots) and does not rule on a single building |
| Missing | The lot has no row in the registration data (`hpdRegistered` false). 393 of the 181,863 registered lots have rows but no usable registration (a placeholder id 0 on 3 lots, or a missing or placeholder BIN): reported as registered with `noUsableRegistration`; lapsed and older-than-deed are then `cannot-tell`. A lot outside the rental scope (unregistered, under 3 units) is not in the graph, and the answer says so |
| Lapsed | Judged by the registration end date against the as-of date: `holds` when every registration of the lot has ended before it; `does-not-hold` when any has not (1,073 lots have both ended and running registrations; each is listed); `cannot-tell` when there is none, or an end date is absent because HPD's rows disagree. The last registration date is not used, so 3,178 lots whose registrations are all undated are still judged by the end date. A lapsed period is HPD's record, not a ruling that the owner is in violation |
| Older than the latest deed | The lot's latest `lastRegistered` (undated registrations ignored) against the latest deed's recorded date among the eight deed types; deeds recorded the same day are all returned. `holds` when the registration is earlier; `does-not-hold` when it is the same day or later; `cannot-tell` with no deed in the snapshot, no dated registration or no registration. The deed carries the not-a-sale flag (amount 0, CORRD or CONDEED) so a correction or a $0 deed is not read as a sale |
| Unit threshold | PLUTO `unitsres` of 3 or more meets it; 1 or 2 is below; 0 or no PLUTO value is not recorded. The answer states the threshold and does not rule on legal applicability (a smaller building can also be registrable) |
| Newly built | A lot with a recent PLUTO year built and no registration is reported with that year. The data does not say why it is unregistered |
| As-of date | The registration data runs through 2026-05-29 and ACRIS through 2026-05-29 (good through 2026-05-31). Every answer states both, and the PLUTO release (26v1). Later public records are a freshness limit, not a failure |

## Who asks and why

An unregistered or lapsed owner has no contact on file for tenants.

## Required content of an answer

1. Yes or no for each condition: missing, lapsed, older than the latest deed. Each with its dates.
2. The residential unit count and the dataset's 3+ unit threshold.
3. The snapshot date of each source.

## Caveats the answer must carry

- Do not rule on legal applicability beyond the stated threshold.
- Absence from the dataset is not a ruling that no registration exists. Newly built buildings can be unregistered for a legitimate reason, and the answer says it does not know.
