# Q23: Managing agent footprint

**Fixture status:** Examples are provisional until verified against the selected frozen snapshot, pinned BOR release, or versioned retrieval cache, as applicable. Existing local checks retain their stated query dates; they are not a frozen acceptance baseline. See [expected-answer policy](../roadmap.md#expected-answer-policy).

## Question

> Which buildings does this managing agent disclose in HPD registrations, and how does that set relate to the building's Operational Network and Owner Portfolio? Is the agent an operator tied to the owner, or a commercial service?

## Who asks and why

A shared agent can connect buildings, or only show that one company manages many clients.

### Sub-questions

CLaRO-style cleanup (stage 1, 2026-11-19). No new graph element: agents are `Contact` nodes of type Agent with `nameKey`; buildings and lots come from `HAS_REGISTRATION` and `HAS_BUILDING`; layers from `IN_NETWORK` and `IN_PORTFOLIO`; masks from Q6. Counts are computed at answer time. The parent passes when all three pass.

| ID | Sub-question | Answer requirements covered |
| --- | --- | --- |
| Q23.1 | Which registrations, buildings and lots disclose this managing agent name, in which spellings and contact type? | 1 (spellings, rule), 2 (registrations, buildings, type) |
| Q23.2 | Of the lots of those buildings, how many are in the reference building's Operational Network and Owner Portfolio, in another group, or in none? | 3 |
| Q23.3 | At which business addresses does the agent appear, and did either method mask any? | 4 |

"Operator tied to the owner, or a commercial service?" is not answered: the footprint size and layer counts are reported with the caveat, never a verdict.

## Required content of an answer

1. The agent as recorded, with the spelling variants combined and the rule used.
2. The registrations and buildings that disclose it, and the contact type.
3. How many of those buildings are in the building's Operational Network and Owner Portfolio, and how many are not.
4. Whether the agent's address is on the mail-drop list.

## Caveats the answer must carry

- A shared agent is a management relationship, not ownership.
- A large footprint suggests a commercial service. It does not prove one.
- Spelling variants are combined by a stated rule, so the counts are derived.

## Worked examples

| Case | Input | What the answer shows | Why it matters |
| --- | --- | --- | --- |
| Large footprint | `BRIGHTON MANAGEMENT` | 42 registrations disclose a name beginning `Brighton Management`, in three spellings: `BRIGHTON MANAGEMENT` (35), `Brighton Management` (5), `BRIGHTON MANAGEMENT LLC` (2). All are contact type `Agent`; `GEN.PART` is HPD's contact description, not a type. Under rule N3 the first two combine (40 registrations); `BRIGHTON MANAGEMENT LLC` (2) is a different name and is reported apart | Spelling variants change the count |

The layer comparison needs the BOR release and is not in the local database.
