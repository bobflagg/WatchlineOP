# Q24: Starting from a name

**Fixture status:** Examples are provisional until verified against the selected frozen snapshot, pinned BOR release, or versioned retrieval cache, as applicable. Existing local checks retain their stated query dates; they are not a frozen acceptance baseline. See [expected-answer policy](../roadmap.md#expected-answer-policy).

## Question

> Given an entity or person name instead of an address, which buildings and roles do the records show for that name, and how reliable is the match?

## Who asks and why

Tenants often know the landlord's name from a lease or a letter, not the address.

### Sub-questions

CLaRO-style cleanup (stage 1, 2026-11-19). No new graph element: names are found through `nameKey` (HPD corporation names, deed grantees and grantors, DOS entities) and, for a person, by `personName`; buildings and lots come from `HAS_REGISTRATION`, `HAS_BUILDING` and `HAS_DEED`. Outcome, basis, leads and counts are computed at answer time. The parent passes when all four pass.

| ID | Sub-question | Answer requirements covered |
| --- | --- | --- |
| Q24.1 | Which records carry this entity name, in what role, on which registration, deed or DOS record, and for which building and lot, with the basis (exact or normalized)? | 1 (rule N3), 2 (matches) |
| Q24.2 | Which records carry this person's name, in what roles, and how many? (leads only, both name orders for deed parties) | 2 (person roles), caveat on common names |
| Q24.3 | Which other names look like this entity name (a legal suffix or a longer name), as leads apart from the matches? | 3 (near-matches) |
| Q24.4 | What is the outcome (matches, leads only, no match in these sources), and what are each source's snapshot date and the caveats? | 1, 4, caveats |

Findings (profiled 2026-11-19): HPD records people first name first and ACRIS deed parties last name first (of 18,141 two-word individual owners, 1,696 equal a grantee name as given and 13,003 equal one reversed), so a person is searched in both orders. 203,475 distinct person names in 615,846 contacts; the most common has 879 contacts and 8,205 names have 10 or more. DOS records are in the graph only when their name equals an HPD owner or grantee name. "Filer" is not a role in any loaded source and is dropped. Lots are the lots of the matched buildings (a BIN on two lots counts toward both). Person fixtures are rules, never names.

## Required content of an answer

1. The name as given and the normalization rule used.
2. For each match: the source, the role (registered owner, officer, agent, grantee, grantor, filer), the building or lot, and the matching basis (exact or normalized).
3. Near-matches shown as leads, separately from matches.
4. The snapshot date of each source.

## Caveats the answer must carry

- A name match is a lead, not a link. Common personal names return unrelated people.
- Roles are reported as recorded. A name in a role is not a finding about ownership.
- A name that matches nothing is "no match in these sources", not "does not exist".

## Scenarios

- A name matches an HPD owner and also an officer of another entity: both roles returned, kept separate.
- A common personal name matches many registrations: returned as leads only, with the count.
- A name matches nothing: "no match in these sources", with the normalization used.
- A name differs from a record only by a suffix or punctuation: reported as a normalized match, with the rule.
