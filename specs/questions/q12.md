# Q12: Transfers of a lot

**Fixture status:** Examples are provisional until verified against the selected frozen snapshot, pinned BOR release, or versioned retrieval cache, as applicable. Existing local checks retain their stated query dates; they are not a frozen acceptance baseline. See [expected-answer policy](../roadmap.md#expected-answer-policy).

## Question

> What deed transfers are recorded for this lot in the selected period, and for the lots currently attributed to its Owner Portfolio? Which of them can be attributed to the currently identified owner?

### Sub-questions

CLaRO-style cleanup (stage 1, 2026-11-16). The parent asks for deeds of one lot, the same for a portfolio, and an attribution. Tests and ontology fragments reference these IDs. Q12 keeps its ID and passes when all three pass. The deeds, dates, amounts and grantees already exist (Q3); Q12 adds the grantors and a name key on every deed party. The period, the counts, the not-a-sale flag and the attribution are computed at answer time, not stored.

| ID | Sub-question | Answer requirements covered |
| --- | --- | --- |
| Q12.1 | Which deeds are recorded against this lot in the period, with dates, amount, grantors and grantees, and how many are there and how many were not sales? | 1 (timeline), 2 (deed count, not-sale count) |
| Q12.2 | Which deeds are recorded in the period against the lots currently attributed to this lot's Owner Portfolio, each counted once, in which run? | 3 (portfolio lots), 4 (run) |
| Q12.3 | For each of those deeds, does a grantee or grantor carry the same name as a currently registered corporate owner of a lot the deed covers? | 3 (attributable or not) |

### Hidden assumptions made explicit (profiled 2026-11-16)

| Assumption | Rule |
| --- | --- |
| "Transfers" are sales | Deeds are counted (Q3 types). A deed is **not a sale** when its recorded amount is 0, or its type is a correction or confirmatory deed (CORRD, CONDEED). 790,381 of 1,003,931 deeds have amount 0 (79 percent, many from the 1960s and 1970s), and 5,785 are CORRD or CONDEED. A deed with an amount is reported as recorded; the answer does not call it a sale of the building |
| One deed per lot | A multi-lot deed is one deed (anchor: `2020021400087001` covers three lots). `otherLots` shows the others; a portfolio count takes distinct deeds |
| "Selected period" | Inclusive bounds on the recorded date, or open. The recorded date is never null on a deed; the document date can be |
| Grantor and grantee | Grantors are partytype 1 (not loaded in Q3), grantees partytype 2. 1,619,378 distinct grantor rows on the 1,003,931 loaded deeds (a count of the same scale as the 1,520,638 grantees, profiled with `scripts/profile_q12_scope.py`; 4 deeds have none, 294 rows have no name). The same name on both sides is kept as recorded (anchor A, 2025) |
| "The currently identified owner" | The CorporateOwner contacts (rule N3) on the HPD registrations of the lot's buildings. Individual owners are not comparable (HPD and ACRIS spell the order of a person's name differently), so such a lot is "owner not comparable". A portfolio has no owner name; each portfolio lot is compared with its own registered owners |
| Attribution is historical | It is not. Current registration is not historical ownership, a name match is a lead (rule N3), and an owner spelled differently in the two sources is missed (anchor C: HPD "438 52 ST OWNERS CORP") |
| Portfolio membership is stable | Ids are valid only inside run 2026-05-29-869bd299; the portfolio is an apparent-owner attribution, a lead to verify |

## Who asks and why

It answers "does my landlord sell frequently, or hold?"

## Required content of an answer

1. A timeline of deeds for the lot: document id, document date, recorded date, amount, grantor and grantee.
2. The count of **deeds**, with the number that were not sales.
3. For portfolio lots: the same, with each transfer marked attributable or not to the currently identified owner.
4. The portfolio run, if portfolio lots are included.

## Caveats the answer must carry

- Count deeds, not lots. A multi-lot deed is one deed covering several lots.
- A `$0` deed is not a sale.
- Attributing a transfer to the current owner is derived. Current membership is not historical ownership.

## Scenarios

- A sale recorded within a month of a new registration: both reported with dates, and the answer says nothing about intent.
- A lot sold as part of a multi-lot deed: reported once as a deed with the lots it covers.
